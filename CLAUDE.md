# Fresa — правила для Claude Code

Перед работой прочитай: этот файл → `docs/AI_PROGRESS.md` → `docs/AI_DECISIONS.md` → `docs/AI_KNOWN_ISSUES.md`. Не утверждай, что помнишь прошлые сессии, если этого нет в файлах.

## Продукт

Fresa — G-код для фрезерных станков с ЧПУ (Fanuc 0i-MF Plus у владельца). Android (RuStore, `app.fresa.cnc`), Windows (EXE), iPhone (Safari/PWA, https://mxdxck.github.io/g-code-cnc/). Язык интерфейса — русский. Пользователь — практик-станочник, объяснять просто.

## Устройство кода

- Вся логика — `index.html` (один `<script type="module">`, ~3100 строк). Разделы помечены комментариями `/* ---------- … */` — см. карту в `docs/AUDIT.md` §1.
- Обработчики в разметке (`onclick="…"`) вызывают только то, что есть в `window.*`: константы модуля (`st`, `save`, `num` …) там не видны — экспортируй явно.
- `save(true)` — сохранить, не сбрасывая ручную/открытую программу; `save()` — сбрасывает ручные правки и пересобирает код по операциям (кроме случая, когда открыта своя программа и операции не менялись).
- `APP_VERSION` в `index.html` и `version.json` поднимаются вместе. Поле `android` в `version.json` — версия, уже одобренная в RuStore.
- Android: `android/` (WebView, мост `AndroidApp`). Windows: `windows/` (WebView2). Ключ подписи — только секреты GitHub. **applicationId и ключ не менять.**

## Ветки и релизы

- Работа над ИИ — ветка `feature/fresa-local-ai`. В `main` — только по согласованию с владельцем.
- `build.yml` собирает и публикует GitHub Release **только из `main`**.
- RuStore: APK загружает владелец вручную. Ничего не публиковать без согласования.

## Правила ИИ-разработки (из ТЗ владельца)

1. Никаких платных API, облачного inference, аренды GPU, обязательной регистрации.
2. Нейросеть не считает траектории — только детерминированное CAM-ядро (OPS и генераторы в `index.html`).
3. Распознанное ≠ подтверждённое; в CAM — только подтверждённое пользователем.
4. Не выдумывать размеры, параметры стоек, M-коды, PMC-сигналы.
5. Не выдавать прототип за промышленную CAM-систему; 3D — не проверка столкновений с оснасткой.
6. После каждого этапа: тесты + обновить `docs/AI_PROGRESS.md`, `AI_KNOWN_ISSUES.md`, `AI_DECISIONS.md`.
