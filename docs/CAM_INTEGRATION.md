# Интеграция с CAM Fresa

Статус: проект. Правило: **CAM Planner выдаёт только существующие операции `OPS` (`index.html:522`)**. Если признаку нет соответствия — статус `unsupported` и объяснение, никакой «самодельной» траектории.

## Признак → операция

| Признак (Schema) | Операции Fresa | Параметры из схемы | Что спросить у пользователя |
|---|---|---|---|
| Hole d ≤ 13, сквозное/глухое | `drill` (центровка `center` + сверление, цикл G81/G83 по глубине) | точки → `PAT list` или распознанный массив | глубина, если `null`; материал |
| Hole с резьбой M | `drill` под резьбу + `tap` или `thread` | шаг из обозначения (таблица резьб уже есть — меню «Резьбы») | метчик или резьбофреза |
| Hole d > 13 (нет сверла) | `helix` (in, circle) или `pocketCircle` | d, глубина | инструмент |
| HolePattern pcd/grid/line/arc | `drill` + `PAT pcd/grid/line/arc` | параметры массива | — |
| Pocket rect / circle | `pocketRect` / `pocketCircle` | cx, cy, w, h / d, depth, R у дна | шаг Z |
| Pocket произвольный (+ острова) | `contour` (основа) + `pocketIsl src:'op'` — как делает `skAuto` (`index.html:3008`) | контур | — |
| Slot | `slot` (ширина = Ø фрезы) или `pocketOval` (ширина > Ø) | x1,y1,x2,y2,w,depth | — |
| ClosedContour внешний | заготовка-контур (`stock custom`) и/или `contour` side out (подвод снаружи — `leadOp` `index.html:1360`) | els | — |
| Chamfer по кромке | `chamf` (src rect/circle/op) | size | фаскосниматель |
| Плоскость (верх) | `face` | габарит заготовки | припуск |
| Fillet | учитывается в контуре (дуги) | r | — |
| Шероховатость / допуск | влияет на выбор: черновой + чистовой проход (у «Контура по элементам» есть проходы с припуском `passes`/`so`; для карманов — две операции: черновая с припуском и чистовая), развёртка `reamer` при H7. Отдельного параметра «чистовой проход» у всех операций сейчас нет — это доработка CAM, а не ИИ | tol | — |
| UnknownFeature | — | — | показать, в CAM не идёт |

## Порядок операций (предложение, не догма)

торцовка → контуры/карманы черновые → чистовые → центровка → сверление (меньшие Ø раньше) → резьба → фаски. Это то же, что подсказывает режим «Новичок» (`GUIDE`, `index.html:786`).

## Инструменты

Сначала — из магазина пользователя (`st.tools`); если нужного нет — предложение `newTool(type,d)` с режимами по материалу (`applyMat`). Подбор концевой фрезы под узкий карман — как `skMill` (≤ 0.7 ширины).

## Воспроизводимость

Одни и те же `confirmed` + настройки → те же `st.ops` → тот же G-код (генераторы детерминированы; регрессионный тест сравнивает G-код побайтно — `tests/` после переноса).
