## Приняты (из ТЗ владельца, 2026-11-10)

- **D-01** Все вычисления ИИ — на устройстве; нет платных API, аренды GPU, облачного inference, обязательных подписок и регистрации, VPN. — ТЗ §0, §2.
- **D-02** Нейросеть не строит траектории; CAM — детерминированное ядро Fresa. — ТЗ §16.
- **D-04** Работа в ветке `feature/fresa-local-ai`; `main` и RuStore — только по согласованию. Сборка релизов запускается только из `main` (`build.yml`), поэтому ветка ничего не публикует. — ТЗ §32.
- **D-05** applicationId `app.fresa.cnc` и ключ подписи не меняются. — ТЗ §25.
- **D-06** iPhone — только веб/PWA, без нативного приложения. — ТЗ §2 п.4.

## Предложены в аудите (ждут владельца)

- **D-03** TypeScript: новые модули на JS + JSDoc-типы + проверка `tsc --checkJs` в CI, без сборщика; `index.html` не переносим. Альтернатива — esbuild в Actions.
- **D-07** Первый прототип (пластина с 4 отверстиями) — без VLM; VLM подключается после как измеримое улучшение.
- **D-08** Основная модель для Android/Windows — Qwen3-VL-2B (Apache-2.0); выбор окончательный только после замеров.
- **D-09** Хостинг моделей: Android/Windows — GitHub Releases (+ зеркало Hugging Face); браузер — Hugging Face; везде SHA-256.
- **D-10** Хранилище: IndexedDB для чертежей, изображений и моделей; JSON проекта — как сейчас (обратная совместимость).
- **D-11** Лицензия репозитория: сейчас публичный и без LICENSE — нужно решение владельца (закрыть или выбрать лицензию).
- **D-12** Дообучение модели на чертежах ГОСТ (разовая работа на GPU, не сервер для пользователей) — допустимо ли и на каких данных.
