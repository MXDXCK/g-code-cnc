# Тестовая сборка Fresa (Android и Windows)

Тестовые сборки нужны, чтобы проверить новое из ветки `feature/fresa-local-ai` на своём телефоне и ПК **до** выпуска. Они ничего не публикуют и не заменяют рабочую Fresa.

## Где взять

1. Откройте https://github.com/MXDXCK/g-code-cnc/actions/workflows/build-check.yml (нужно войти в GitHub — файлы сборок доступны только вошедшим).
2. Выберите верхний запуск с зелёной галочкой для ветки `feature/fresa-local-ai`.
3. Внизу страницы, в разделе **Artifacts**:
   - `Fresa-TEST-android` — APK для телефона;
   - `Fresa-TEST-windows` — EXE для ПК.
4. GitHub отдаёт каждый файл в zip-архиве — распакуйте его. Файлы хранятся 14 дней.

Номер сборки виден в имени файла и в приложении: `2.9.2-test.N+abcdef1`. N — номер запуска, abcdef1 — коммит. Тот же номер показан в шапке: «v2.9.2 · ТЕСТ test.N+…».

## Android: чем тестовая сборка отличается от рабочей

| | Fresa из RuStore | Fresa ТЕСТ |
|---|---|---|
| Имя приложения | Fresa | Fresa ТЕСТ |
| applicationId | app.fresa.cnc | app.fresa.cnc.test |
| Подпись | ключ релиза | отладочная (debug) |
| Данные, проекты | свои | **отдельные** — рабочие проекты не видны и не трогаются |
| Обновления | через RuStore | не предлагаются |

Почему отдельное приложение: Android ставит обновление поверх только при **той же подписи**. Отладочная подпись не совпадает с ключом релиза. Поэтому APK с тем же applicationId пришлось бы ставить через удаление рабочей Fresa, а вместе с ней удалились бы и проекты. Тестовая сборка с другим applicationId ставится **рядом**, ничего не удаляя.

### Установка на телефон

1. Скачайте `Fresa-TEST-….apk` на телефон или перенесите его с компьютера.
2. Откройте файл. Android попросит разрешить установку из этого источника (браузера или «Файлов») — разрешите.
3. Нажмите «Установить». Появится второй значок **Fresa ТЕСТ**, рабочая Fresa остаётся.
4. Перенести проект из рабочей версии в тестовую: в Fresa — «⬇ Экспорт текущей файлом .nc», в Fresa ТЕСТ — «Открыть файл .nc».
5. Удаление тестовой версии не затрагивает рабочую.

## Windows

- `Fresa-TEST-….exe` — один файл, установка не нужна.
- Данные хранятся в `%LOCALAPPDATA%\GcodeCNC-Test`, рабочие (`GcodeCNC`) не трогаются.
- Заголовок окна: «Fresa ТЕСТ».
- Нужен Microsoft Edge WebView2 Runtime — в Windows 10/11 он обычно уже есть.
- SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Что проверить (по порядку)

1. «По чертежу» → PDF и фото из `tests/fixtures/drawings/` (или ваши) → подтверждение → G-код → «Проверка программы» → 3D.
2. Режим полёта (без интернета): PDF, фото, 3D должны работать — библиотеки внутри приложения.
3. Закрыть и открыть приложение — проект и «Открыть исходник» на месте.
4. Записать модель телефона и версию Android (или Windows), время распознавания фото и всё, что работало не так.
