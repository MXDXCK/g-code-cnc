# Матрица распознавания эталонных чертежей

Обновляется командой: `npx playwright test tests/e2e/drawing-set.spec.js && node tests/matrix-report.js`. Эталоны и генератор — `tests/fixtures/drawings/` (`gen-plate.js`, `gen-set.js`), эталонная геометрия — `expected.json` в каждой папке.

**Это синтетические чертежи** (нарисованы программой по ГОСТ 2.307). Они проверяют алгоритм, но **не заменяют проверку настоящих фотографий и сканов** — таких испытаний ещё не было.

Колонки: «Отверстия» — найдено с верными X/Y; «Лишние» — найдено сверх эталона (или без координат); «По размеру» — сколько значений взято из размерных надписей (остальные — «измерено» или пусто); «Неверных «по размеру»» — жёсткое требование, всегда 0.
