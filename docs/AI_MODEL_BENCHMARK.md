## Метрики

| Метрика | Как считается |
|---|---|
| Отверстия: recall / precision | совпадение центра ≤ 0.5 мм (вектор) / ≤ 2% габарита (фото) и Ø ± 0.1 |
| Размеры: точность чтения | доля размерных чисел, прочитанных точно (строка в строку) |
| Связь размер↔элемент | доля правильных связей |
| Галлюцинации | доля элементов/размеров, которых нет на чертеже |
| Время | от «Распознать» до списка (холодный и тёплый запуск) |
| Память | пик RSS / GPU (Android: `Debug.getNativeHeapSize`, Windows: процесс, Safari: факт падения вкладки) |
| Батарея / температура | Android: BatteryManager до/после 10 прогонов |
| Правки пользователя | сколько полей пришлось исправить до подтверждения |
