# G-код ЧПУ

Генератор G-кода для фрезерных станков **Fanuc 0i-MF Plus**: циклы как у Siemens ShopMill, живая 3D-модель результата, параметрические программы (макро B) и 3D-симуляция обработки.

**Открыть в браузере:** https://mxdxck.github.io/g-code-cnc/

## Установка

| Устройство | Как установить |
|---|---|
| **iPhone / iPad** | Откройте https://mxdxck.github.io/g-code-cnc/ в **Safari** → «Поделиться» → «На экран „Домой“». Работает без интернета (после первого открытия), обновляется сама. Файлы `.nc` — через «Поделиться» → «Сохранить в Файлы». |
| **Android** | Скачайте `GcodeCNC-*.apk` из [Releases](https://github.com/MXDXCK/g-code-cnc/releases/latest) и установите (разрешите установку из этого источника). Новая версия ставится поверх старой — проекты и настройки сохраняются. Файлы сохраняются в `Загрузки/CNC`. |
| **Windows 10/11** | Скачайте `GcodeCNC-*.exe` из [Releases](https://github.com/MXDXCK/g-code-cnc/releases/latest) и запустите — установка не нужна. Нужен Microsoft Edge WebView2 Runtime (в Windows 10/11 обычно уже есть; если нет — программа предложит скачать). **F11** — полный экран. |

APK и EXE работают полностью без интернета.

## Возможности

**Циклы (галерея с пиктограммами, свои пресеты):**
- Торцевание
- Карманы: прямоугольный, круглый, овальный, гнездо многогранника (с радиусом у дна), **карман с островами** и карман по контуру с чертежа
- Выступы и контуры: прямоугольный, круглый, овальный, многогранник, шестигранник на круглом прутке
- Контур по элементам с чертежа (прямые и дуги) + импорт **DXF** (КОМПАС, AutoCAD), зеркальные копии, обработка справа/слева по очереди
- Дуга — часть окружности (справа, слева, сверху, снизу, по углам)
- Винтовое фрезерование — внутреннее и наружное: окружность, прямоугольник, многогранник
- Канавки по профилю (растр): U с радиусом у дна, полукруглая, V
- Пазы: прямой, радиальные на окружности (2, 4, 6…), дуговые на окружности
- Лыски на круглой и квадратной заготовке
- Отверстия: сверление G81/G82/G83/G73, жёсткое нарезание резьбы M29+G84, резьбофрезерование; по списку, по окружности (PCD), по дуге, в ряд, массивом, по рамке
- **Отверстие под резьбу** — мастер: центровка с фаской → сверло → метчик или резьбофреза, инструмент подбирается сам
- Фаска фаскоснимом: прямоугольник, отверстие, контур с чертежа
- Гравировка текста: однолинейный шрифт (русский, латиница, цифры, знаки), по прямой или по дуге

**Открытие готовых программ:** вкладка G-код → «📂 Открыть файл» (.nc, .txt, без расширения) — 3D, проверка, время. Понимает дуги R и I/J, G41/G42, G81–G84 с G98/G99, G91, ось A, диаметр инструмента из комментария (FREZA D6).

**Программа с фото:** вкладка G-код → «📷 С фото» (или меню ☰) — фото экрана стойки или распечатки распознаётся прямо на телефоне (Tesseract.js, при первом запуске загружается из интернета), исправляются типичные ошибки, сомнительные строки подсвечиваются, затем программа открывается и переводится в параметрию.

**Перевод в параметрию:** открытую программу можно перевести в макро B одной кнопкой «🔁 В параметрию» — повторяющиеся проходы по Z сворачиваются в цикл WHILE с переменными (Z первого прохода, шаг, конечная Z, подача). Траектория сверяется с исходной.

**G-код:**
- Параметрический (макро B): размеры операции в `#1…`, режимы фрезы в `#20` (диаметр), `#21` (S), `#22` (F), `#23` (врезание), `#24` (безопасная Z) — меняются прямо на стойке, проходы считаются циклами `WHILE`
- Обычный (развёрнутый) — на выбор
- Пояснения в скобках: русские латиницей (по умолчанию), кириллица или English
- Дробные числа — через точку или запятую

**Заготовка:** прямоугольная, круглая, многогранник, произвольный контур или **пруток на 4-й оси A** (3D с поворотом детали). Несколько деталей на столе — массив через G52 или своя G54…G59 у каждой.

**3D:** модель результата прямо в редакторе операции, полная симуляция программы (в т.ч. макро и ручных правок), учёт формы инструмента (концевая, сферическая, радиусная, конус фаскоснима и сверла).

**Меню ☰:** лист наладки (печать / PDF), «Мои детали», проверка программы (G0 в материал, без шпинделя, H≠T…), калькулятор режимов по материалу с утончением стружки, справочник G/M-кодов и тревог Fanuc, таблица резьб, допуски.

## Как обновить

1. Измените `index.html` и поднимите номер версии в `version.json`.
2. Сделайте commit в `main`.

Дальше всё автоматически:
- **GitHub Pages** обновляет веб-версию (iPhone и браузер получат её сами; в приложении — вкладка «Обновл.» → «Проверить обновления»);
- **GitHub Actions** собирает новые APK и EXE и публикует их в [Releases](https://github.com/MXDXCK/g-code-cnc/releases) с описанием изменений из `version.json`. Приложения на Android и Windows сами сообщают о новой версии на вкладке «Обновл.».

## Устройство репозитория

| Путь | Что это |
|---|---|
| `index.html` | Всё приложение (одна страница) |
| `version.json` | Номер версии и список изменений |
| `sw.js`, `manifest.webmanifest`, `icons/` | Установка на iPhone и работа без интернета |
| `android/` | Оболочка Android (WebView): сохранение файлов в «Загрузки/CNC», «Поделиться» |
| `windows/` | Оболочка Windows (WebView2, .NET 8): один exe-файл |
| `.github/workflows/build.yml` | Сборка APK и EXE и публикация в Releases |

> Перед первым запуском программы на станке проверьте её в графике стойки или «по воздуху». Параметрический режим требует опцию Custom Macro B (на 0i-MF Plus обычно есть).
