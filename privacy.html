FRESA

Политика конфиденциальности

Приложение «Fresa — G-код для ЧПУ» · редакция от 1 ноября 2026 г.
Коротко: приложение не собирает и не передаёт ваши персональные данные. Всё, что вы вводите — проекты, программы, фото, — хранится и обрабатывается только на вашем устройстве.

1. Какие данные обрабатываются

  • Проекты, инструмент, операции, G-код — хранятся в памяти приложения на вашем устройстве (локальное хранилище браузера / WebView). На серверы не отправляются.
  • Фото программы («Программа с фото») — распознаются прямо на устройстве. Изображение никуда не загружается и не сохраняется после распознавания.
  • Файлы, которые вы открываете или сохраняете, остаются на вашем устройстве; их отправка другим людям происходит только по вашей команде («Поделиться»).

2. Сетевые запросы

  • Проверка обновлений: приложение запрашивает файл с номером версии (version.json) с GitHub Pages. Передаётся только обычный технический запрос, без данных о вас и ваших проектах.
  • Веб-версия при первом открытии загружает библиотеки (three.js, распознавание текста) с публичных CDN (unpkg.com, cdn.jsdelivr.net). В версиях для Android и Windows эти библиотеки встроены.
  • Приложение не использует рекламу, аналитику, трекеры и cookies для отслеживания.

3. Разрешения

  • Камера / фото — только когда вы сами нажимаете «Сфотографировать / выбрать фото».
  • Файлы — только для открытия и сохранения выбранных вами файлов (на Android — в папку «Загрузки/CNC»).

4. Удаление данных

Удалите проекты в приложении («Проект» → «Новый проект», «Мои проекты» → удалить) или удалите само приложение — вместе с ним удалятся все данные.

5. Дети

Приложение предназначено для специалистов по металлообработке и не ориентировано на детей.

6. Изменения

При изменении политики новая редакция публикуется на этой странице с указанием даты.
