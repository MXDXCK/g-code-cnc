## Состояние

- **«По чертежу»** (меню ☰ и главный экран):
  - вход — DXF, PDF или фото; размеры привязываются к линиям по ГОСТ 2.307 (`src/drawing/`, `docs/DIMENSION_ASSOCIATION.md`);
  - элементы: окружности, прямоугольные карманы, пазы, контур детали (`src/drawing/features.js`, `associate.js`);
  - операции (только существующие генераторы, D-26): сверление G81, «Карман прямоугольный / овальный / круглый»,
    «Контур по элементам» (наружный контур, сквозное окно), «Фаска по контуру»;
  - всё решает человек: что это за элемент, глубина, фреза, шаги, врезание, ноль; запреты — D-27;
  - фото: два прохода OCR — eng (числа, Ø) + rus+eng (русские слова), выравнивание освещения (D-28).
- **Проверка программы** — ошибки, предупреждения, «не проверено» (`modalChecks`).
- **ИИ-помощник** (`src/ai/`) — выключен по умолчанию, только подсказки; Ollama на ПК необязательна; Android и браузер — «не встроено».
- **Тестовые сборки:** APK «Fresa ТЕСТ» (`app.fresa.cnc.test`) и EXE «Fresa-TEST» из `build-check.yml` (`docs/TEST_BUILD.md`).
- **Свои чертежи владельца** — `tests/fixtures/private/README.md`, `npm run test:private`, в git не попадают (D-29).
